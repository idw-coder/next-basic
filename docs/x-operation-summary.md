# ウェブエンジニア問題集 X運用まとめ

## サイト概要

- URL: https://study.ntorelabo.com/
- 駆け出しエンジニア向けの無料学習サイト
- 15カテゴリ・509問+のクイズ中心
- 会員登録なしでも利用可、Google認証あり、サブスク準備中
- 教科書（Books）機能もあり

## Xアカウント情報

- 表示名: ウェブエンジニア問題集
- @ID: @web_eng_quiz
- プロフィール文: 「駆け出しエンジニア向けにクイズを出題。HTML/CSS/JS/React/Vue/AWS etc. 15カテゴリ・509問+が無料で解ける学習サイトを運営中。」
- プロフィール画像: サイトロゴ（電球+はてなマーク）を使用（設定済み）
- WebサイトURL欄: https://study.ntorelabo.com/

## 固定ポスト（設定済み）

```
ウェブエンジニア問題集 - 駆け出しエンジニア向けの無料学習サイト

1問30秒から。スキマ時間にサクッと力試し
HTML / CSS / JS / React / Vue / AWS など15カテゴリ・509問+

会員登録なしですぐ始められます
https://study.ntorelabo.com/
```

## 運用方針（3軸）

1. **日次クイズ出題（メイン軸）** - サイトへの流入を狙う
2. **解説ポスト（権威性）** - 週2〜3回、半自動化想定
3. **機能リリース告知（既存ユーザー維持）** - 発生時のみ手動

※「トレンド便乗」は軸から外した。学習サイトのブランドと相性が悪いため。

## クイズ投稿フォーマット

```
【○○クイズ】
（問題文を短く）

A. 選択肢1
B. 選択肢2
C. 選択肢3
D. 選択肢4

答えと解説はこちら
（カテゴリ別URL）
```

- 140文字制限のため、選択肢が長い場合は問題画面のスクショを画像添付し、投稿テキストは問題文+URLのみにする
- URLは直貼りでOK（フォロワーが少ないうちはアルゴリズム不利を気にしても意味がない）
- カテゴリごとの個別URLにリンクする（サイトトップではなく）

## 投稿スケジュール

- **投稿時間: 毎日21時**（駆け出しエンジニアの学習タイムに合わせる）
- カテゴリは毎日変える（サイトの幅広さをアピール）
- PCブラウザから予約投稿が使える（無料アカウントでOK、スマホアプリからは不可）

```json
    { "choice_text": "選択肢3", "is_correct": false },

  "tags": ["タグ1", "タグ2"]

```

### 選択肢作成のルール（プロンプトに追加済み）

- 不正解の選択肢は、関連する別の概念や機能との混同を狙う。明らかに無関係な選択肢は避ける
- 4つの選択肢は文体・長さ・具体度を揃える。正解だけが詳しく書かれていると消去法で解ける
- 「初学者がよくやる勘違い」を不正解の選択肢に反映する

### ターゲットレベル

- Xで狙うのは初学者層（Progateやったくらい）
- 選択肢はシンプルに単語 or 短文
- 解説は平易な言葉で

## URL問題への対応方針

- フォロワーが少ないうちはURL直貼りで流入優先
- フォロワーが増えてきたら、URL無し投稿でリーチを取りつつリプやスレッドでURL補足に切り替える
- プロフィールのWebサイト欄が常設の導線

## 自動化（Bot化）の方針（未着手）

- 日次クイズ: 完全自動化予定（DBから1日1問取得→X API v2で投稿、cron）
- 解説ポスト: Claude APIで下書き生成→人間が確認・調整
- 機能告知: 手動のまま
- スクショ自動化: Puppeteer等で問題画面のキャプチャを自動生成

## OGP画像

`ciw`や`di"`は暗号ではありません。Vimは「何をするか」と「どこにするか」を文法のように並べます。

<Marker>Vimの編集コマンドは、基本的に`{回数}{オペレーター}{範囲}`の順です。</Marker>

## オペレーターで操作を選ぶ

| オペレーター | 元の語 | 動作 |
| --- | --- | --- |
| `d` | delete | 削除する |
| `c` | change | 削除して挿入モードへ入る |
| `y` | yank | コピーする |

範囲には、移動コマンドまたは**テキストオブジェクト**を続けます。テキストオブジェクトとは、単語や引用符の内側など、意味のあるまとまりを表す範囲です。

```text
d + w = dw   次の単語位置まで削除
c + iw = ciw カーソル位置の単語を変更
y + i" = yi" 二重引用符の内側をコピー
```

## iwとawの違い

`i`はinside（内側）、`a`はaround（周囲を含む）を表します。

| 範囲 | 元の語 | 含むもの |
| --- | --- | --- |
| `iw` | inside word | 単語本体 |
| `aw` | around word | 単語と隣接する空白 |

```text
操作前: const |name = value;

diw後: const | = value;
daw後: const |= value;
```

`diw`は単語だけを消し、`daw`は余分になりやすい空白も消します。

## ciwで単語を書き直す

`ciw`はchange inside wordです。カーソルが単語の途中にあっても、その単語を削除して挿入モードへ入ります。

```text
操作前: const user|Nmae = "Taro";
ciw後:   const | = "Taro";       ← 挿入モード
userName<Esc>後:
          const userName = "Taro";
```

`dw`のあとに`i`を押すより、`ciw`なら「単語を変更する」という1つの変更になります。`.`で繰り返しやすい点も利点です。

<SpeechBubble character="/images/usingcomputer_suit_woman_color.png" name="学習者">
`cw`ではなく`ciw`を使うのは、なぜですか？
</SpeechBubble>

`cw`はカーソル位置から単語末尾までを変更します。`ciw`はカーソル位置に関係なく単語全体が対象です。単語の途中にいる場合の結果が分かりやすいため、名前の書き直しには`ciw`が向きます。

## 引用符や括弧の内側を扱う

| テキストオブジェクト | 対象 |
| --- | --- |
| `i"` / `a"` | 二重引用符の内側 / 引用符を含む全体 |
| `i'` / `a'` | 一重引用符の内側 / 引用符を含む全体 |
| `i(` / `a(` | 丸括弧の内側 / 括弧を含む全体 |
| `i{` / `a{` | 波括弧の内側 / 括弧を含む全体 |

```text
操作前: const message = "Hello |world";
di"後:   const message = "|";
da"後:   const message = |;
```

`ci"`なら引用符を残して中身だけを書き直せます。カーソルを引用符の先頭へ正確に合わせる必要はありません。

## 回数を組み合わせる

`2dw`は`2 + d + w`で、2単語ぶん削除します。`d2w`も多くの場合は同じ結果ですが、`{回数}{オペレーター}{範囲}`に揃えると読みやすくなります。

行単位の`dd`、`cc`、`yy`は、同じオペレーターを2回押す形です。

## よくあるハマりどころ

- `d`だけで止まるのは範囲を待っているため。`Esc`で中止できる
- `i`は挿入コマンドにもinside指定にも使われ、直前の状態で意味が変わる
- `di"`はカーソルが対応する引用符の範囲にいないと動かない
- `daw`は空白も対象にするため、`diw`と結果が違う

## ちゃんと使うためのポイント

- `d`は削除、`c`は変更、`y`はコピー
- `iw`は単語本体、`aw`は周囲の空白も含む
- `ciw`は現在の単語全体を書き直す
- `di"`は二重引用符の内側だけを削除する
- コマンドをオペレーターと範囲へ分解して覚える

[検索と置換](/books/vim/search-and-replace)では、同じ文字列を探す`/`、`n`と、一括変更する`:%s`を扱います。

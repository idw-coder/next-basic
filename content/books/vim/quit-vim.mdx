**変更を捨てて今すぐ終了するなら、`Esc`を押して`:q!`と入力し、`Enter`を押します**。

```text
Esc
:q!
Enter
```

**編集内容を保存して終了するなら、`Esc`を押して`:wq`と入力し、`Enter`を押します**。

```text
Esc
:wq
Enter
```

<Callout type="warning" title="保存が必要か分からないときは:q!を急いで実行しない">
`:q!`は未保存の変更を捨てます。コミットメッセージや設定ファイルを残したい場合は`:wq`を使います。
</Callout>

## まずノーマルモードへ戻る

`Esc`を押すのは、Vimを移動や編集の起点となる**ノーマルモード**へ戻すためです。挿入モードのまま`:q!`と入力すると、その5文字が本文へ入ります。

`Esc`を1〜2回押してから`:`を押すと、画面下部にコマンドを入力できます。挿入モードを示す`-- INSERT --`が消えればノーマルモードです。

<SpeechBubble character="/images/usingcomputer_suit_woman_color.png" name="学習者">
`Esc`を押しても画面がほとんど変わらないので、戻れたのか不安です。
</SpeechBubble>

すでにノーマルモードだった場合、`Esc`を押しても本文は変わりません。迷ったときに押して安全なキーとして覚えます。

## :q!と:wqを分解する

`:`から始まる入力は、保存や終了を画面下部から指示する**コマンドラインコマンド**です。

| 部品 | 元の語 | 役割 |
| --- | --- | --- |
| `:` | 開始記号 | コマンドラインを開く |
| `w` | write（書き込む） | バッファをファイルへ保存する |
| `q` | quit（終了する） | 現在のウィンドウを閉じる |
| `a` | all（すべて） | すべてのウィンドウを対象にする |
| `!` | bang（感嘆符） | 通常の安全確認を上書きする |

**バッファ**とは、ファイルを読み込んで編集するメモリ上の領域です。`:w`まで元のファイルは更新されません。

| コマンド | 動作 | 未保存の変更 |
| --- | --- | --- |
| `:q` | 終了 | 変更があれば止まる |
| `:q!` | 保存せず強制終了 | 捨てる |
| `:w` | 保存して続行 | 保存する |
| `:wq` | 保存して終了 | 保存する |
| `:qa!` | すべて強制終了 | すべて捨てる |
| `:wqa` | すべて保存して終了 | すべて保存する |

<Marker>`!`は「強い終了記号」ではなく、Vimが止めている危険な操作を強制する記号です。</Marker>

## 終了できないエラーを読む

`:q`で`E37: No write since last change`が出る場合、Vimが未保存の変更を守っています。残すなら`:wq`、捨てるなら`:q!`を選びます。

`:wq`で`readonly`や権限のエラーが出た場合、`:wq!`でもOSの書き込み権限までは変えられません。

<Callout type="warning" title="権限エラーの直後に:q!を使うと変更を失う">
必要な内容を別ファイルへ保存するか、Vimを開いたまま権限を確認します。
</Callout>

## よくあるハマりどころ

- `:`なしの`wq`は保存終了にならない
- `Ctrl+C`はVimを正常終了する操作ではない
- `:wq!`でもOSの権限不足やディスク容量不足は解決しない
- 複数画面では`:q`が現在のウィンドウだけを閉じることがある

## ちゃんと使うためのポイント

- 最初に`Esc`でノーマルモードへ戻る
- 変更を捨てるなら`:q!`、保存するなら`:wq`
- `w`はwrite、`q`はquit、`a`はall
- `:q`が止まるのは未保存の変更を守るため

[Vimのモード](/books/vim/vim-modes)では、ノーマル、挿入、ビジュアル、コマンドラインの各モードを整理します。

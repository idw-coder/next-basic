この付録は、Vimが突然開いたときに必要な操作を目的から探すためのチートシートです。表の操作は、特記がない限り`vim --clean`で使えるVim標準機能です。

<Callout type="info" title="最初にEscを押す">
現在のモードが分からない場合は、まず`Esc`を押してノーマルモードへ戻ります。終了や保存のコマンドは、そのあとに入力します。
</Callout>

## 保存と終了

| やりたいこと | コマンド | 分解すると |
| --- | --- | --- |
| 保存せず終了 | `:q!` | quitに`!`を付け、未保存の変更を破棄して終了 |
| 保存して終了 | `:wq` | writeしてからquit |
| 保存だけする | `:w` | write |
| 変更がなければ終了 | `:q` | quit |
| すべてのウィンドウを終了 | `:qa` | quit all |
| すべて保存して終了 | `:wqa` | write、quit、all |

未保存の変更が必要か分からない場合は、`:q!`を急いで実行しません。詳しい判断は[Vimを終了する](/books/vim/quit-vim)で確認できます。

## モードを切り替える

| やりたいこと | キー | 入るモード |
| --- | --- | --- |
| カーソルの前から入力 | `i` | 挿入モード |
| カーソルの後ろから入力 | `a` | 挿入モード |
| 行末から入力 | `A` | 挿入モード |
| 下に新しい行を作って入力 | `o` | 挿入モード |
| 文字単位で選択 | `v` | ビジュアルモード |
| 行単位で選択 | `V` | ビジュアルモード |
| 操作モードへ戻る | `Esc` | ノーマルモード |
| 保存や置換のコマンドを入力 | `:` | コマンドラインモード |

## カーソルを移動する

| 移動先 | キー | 覚え方 |
| --- | --- | --- |
| 左・下・上・右 | `h`・`j`・`k`・`l` | ホームポジションで移動 |
| 次の単語の先頭 | `w` | word |
| 前の単語の先頭 | `b` | back |
| 単語の末尾 | `e` | end |
| 行頭 | `0` | 0列目 |
| 最初の非空白文字 | `^` | インデント後の先頭 |
| 行末 | `$` | 正規表現の行末と同じ記号 |
| ファイル先頭 | `gg` | 先頭へ移動 |
| ファイル末尾 | `G` | 最後へ移動 |
| 指定行 | `{行番号}G` | 例: `25G`で25行目 |
| 対応する括弧 | `%` | `()`、`{}`、`[]`の対応先 |

## 削除・コピー・貼り付け

| やりたいこと | キー | 動作 |
| --- | --- | --- |
| 1文字削除 | `x` | カーソル上の文字を削除 |
| 1行削除 | `dd` | deleteを現在行へ適用 |
| 3行削除 | `3dd` | `dd`を3行へ適用 |
| カーソル位置から行末まで削除 | `D`または`d$` | deleteを行末まで適用 |
| 1行コピー | `yy` | yankを現在行へ適用 |
| 行を複製 | `yyp` | yankした行を下へput |
| 後ろまたは下へ貼り付け | `p` | put |
| 前または上へ貼り付け | `P` | put before |
| 取り消す | `u` | undo |
| 取り消しをやり直す | `Ctrl-r` | redo |
| 直前の変更を繰り返す | `.` | 同じ編集を再実行 |

`lD`は単一コマンドではありません。`l`で右へ1文字移動してから、`D`でその位置から行末まで削除する2操作です。

## オペレーターと範囲を組み合わせる

Vimの編集は、`{回数}{オペレーター}{範囲}`の順で組み立てます。

| 操作 | コマンド | 分解すると |
| --- | --- | --- |
| 単語を削除 | `dw` | delete + word |
| 単語の中身を変更 | `ciw` | change + inner + word |
| ダブルクォート内を削除 | `di"` | delete + inner + `"` |
| 行末まで変更 | `c$`または`C` | change + 行末 |
| 3単語コピー | `3yw` | 3 + yank + word |

`c`は削除後に挿入モードへ入ります。削除だけなら`d`、続けて入力するなら`c`を選びます。

## 検索と置換

| やりたいこと | コマンド | 動作 |
| --- | --- | --- |
| 下方向へ検索 | `/文字列` | `Enter`で検索開始 |
| 上方向へ検索 | `?文字列` | `Enter`で検索開始 |
| 次の一致へ移動 | `n` | 同じ検索方向へ移動 |
| 前の一致へ移動 | `N` | 反対方向へ移動 |
| 現在行の最初の一致を置換 | `:s/前/後/` | substitute |
| 現在行のすべてを置換 | `:s/前/後/g` | `g`は行内の全一致 |
| ファイル全体を置換 | `:%s/前/後/g` | `%`は全行 |
| 確認しながら全体を置換 | `:%s/前/後/gc` | `c`はconfirm |
| 検索の強調表示を消す | `:nohlsearch` | 検索結果は保持 |

## ファイル・バッファ・分割

| やりたいこと | コマンド | 動作 |
| --- | --- | --- |
| 別ファイルを開く | `:edit ファイル名` | 現在のウィンドウで編集 |
| バッファ一覧 | `:ls` | 読み込んだファイルを一覧表示 |
| 次のバッファ | `:bnext`または`:bn` | buffer next |
| 前のバッファ | `:bprevious`または`:bp` | buffer previous |
| バッファを閉じる | `:bdelete`または`:bd` | 一覧からバッファを外す |
| 上下に分割 | `:split`または`:sp` | horizontal split |
| 左右に分割 | `:vsplit`または`:vs` | vertical split |
| 別ウィンドウへ移動 | `Ctrl-w w` | windowを順番に移動 |
| ウィンドウを閉じる | `:q` | 現在のウィンドウを閉じる |

## Gitのコミット編集で迷ったとき

```text
i          メッセージを入力できる状態にする
文字を入力  1行目へコミットメッセージを書く
Esc        ノーマルモードへ戻る
:wq        保存してVimを終了する
```

中止する場合は、必要な内容がないことを確認してから`:q!`を使います。[Git commitとSSH先のVim](/books/vim/vim-in-real-work)には実務での判断をまとめています。

## Vim標準とIDE機能を混同しない

| キー | Vim標準での意味 | 注意点 |
| --- | --- | --- |
| `gd` | 現在の関数内にあるローカル宣言へ移動 | LSPによる「定義へ移動」とは限らない |
| `K` | `keywordprg`でキーワードを調べる | 型情報のホバー表示とは限らない |
| `gcc` | 標準操作ではない | Neovimではコメント切り替えとして使える |

<Marker>同じキーでも、Vim、Neovim、LazyVimでは割り当てが異なる場合があります。</Marker>

[Neovim・LazyVimチートシート](/books/vim/neovim-cheatsheet)では、コメント切り替え、LSP、ファイル検索などの追加操作を区別して確認します。

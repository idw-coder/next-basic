Vimでは「どの単位で移動するか」をコマンドで指定できます。1文字、1単語、1行、ファイル全体の順に覚えます。

## 1文字・1行ずつ移動する

```text
        k
        ↑
    h ←   → l
        ↓
        j
```

| キー | 移動 | 覚え方 |
| --- | --- | --- |
| `h` | 左へ1文字 | 4キーのいちばん左 |
| `j` | 下へ1行 | `j`の下側が矢印の先に見える |
| `k` | 上へ1行 | `j`と対になる |
| `l` | 右へ1文字 | 4キーのいちばん右 |

`hjkl`は略語ではありません。矢印キーも使えるため、最初から縛る必要はありません。

## 単語単位で移動する

| コマンド | 元の語 | 移動先 |
| --- | --- | --- |
| `w` | word | 次の単語の先頭 |
| `b` | back | 前の単語の先頭 |
| `e` | end | 単語の末尾 |

```text
移動前: const |userName = "Taro";
wの後: const userName |= "Taro";
eの後: const userNam|e = "Taro";
```

空白で区切られた塊ごと移動する場合は大文字の`W`、`B`、`E`を使います。

## 行の中を移動する

| コマンド | 移動先 |
| --- | --- |
| `0` | 行の先頭列 |
| `^` | 最初の空白でない文字 |
| `$` | 行末 |
| `f{文字}` | 次の指定文字 |
| `t{文字}` | 次の指定文字の直前 |

`f`はfind、`t`はtill（〜まで）の頭文字です。`f"`は次の二重引用符へ、`t"`はその直前へ移動します。

<Marker>コードの行頭へ移動したいときは`^`、画面上の一番左へ戻りたいときは`0`です。</Marker>

## ファイル全体を移動する

| コマンド | 考え方 | 移動先 |
| --- | --- | --- |
| `gg` | 先頭へのコマンド | 最初の行 |
| `G` | Goto | 最後の行 |
| `25G` | 25 + Goto | 25行目 |
| `Ctrl+d` | down | 半画面下 |
| `Ctrl+u` | up | 半画面上 |

多くの移動は`5j`や`3w`のように回数を前へ付けられます。

## よくあるハマりどころ

- 挿入モードの`j`は文字入力になる
- `G`は末尾、`gg`は先頭
- 画面上で折り返された表示行とファイル上の行は別
- `2$`は同じ行末を2回ではなく、次の行の行末まで移動する

## ちゃんと使うためのポイント

- `hjkl`は左、下、上、右
- `w`、`b`、`e`は単語単位
- `0`は列の先頭、`^`は最初の文字、`$`は行末
- `gg`は先頭、`G`は末尾、`25G`は25行目
- 数字を前へ付けると回数を指定できる

[編集の基本](/books/vim/editing-basics)では、`dd`、`yy`、`p`、`u`を使います。

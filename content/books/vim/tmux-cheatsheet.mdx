tmuxは、1つのターミナル内で複数の作業画面を管理し、接続を離れたあとも作業を保持できる**ターミナルマルチプレクサ**です。VimやNeovimの代わりではなく、それらを動かすターミナル側を管理します。

```text
セッション work
├── ウィンドウ editor
│   ├── ペイン Neovim
│   └── ペイン シェル
└── ウィンドウ server
    ├── ペイン 開発サーバー
    └── ペイン ログ
```

| 単位 | 役割 | 近いイメージ |
| --- | --- | --- |
| セッション | プロジェクト全体の作業を保持 | 作業スペース |
| ウィンドウ | セッション内で画面全体を切り替える | タブ |
| ペイン | 1つのウィンドウを分割した区画 | 分割エディタ |

## プレフィックスキー

tmux内のキー操作は、最初に既定のプレフィックスキー`Ctrl-b`を押し、指を離してから次のキーを押します。

```text
Ctrl-b → d
```

これは`Ctrl-b`と`d`の同時押しではありません。以降も`Ctrl-b → キー`と表記します。

tmux内で`Ctrl-b → :`を押すと、画面下部にtmuxコマンドの入力欄が開きます。この入力欄では先頭の`tmux`を省き、`new-session -s work`のようにサブコマンドから入力して`Enter`を押します。`ls`や`git status`などのシェルコマンドを入力する場所ではありません。

## セッションを作る・戻る

次のコマンドは、tmuxの外側にある通常のシェルで実行できます。

| やりたいこと | コマンド | 動作 |
| --- | --- | --- |
| 名前なしで開始 | `tmux` | 新しいセッションを作って入る |
| 名前を付けて開始 | `tmux new -s work` | `work`セッションを作って入る |
| あれば戻り、なければ作る | `tmux new -A -s work` | attachまたはnew |
| セッション一覧 | `tmux ls` | 実行中のセッションを表示 |
| 最後のセッションへ戻る | `tmux attach` | 省略形は`tmux a` |
| 名前を指定して戻る | `tmux attach -t work` | targetに`work`を指定 |
| 指定セッションを終了 | `tmux kill-session -t work` | `work`を終了する |

`-s`はsession-name、`-t`はtarget、`-A`は既存セッションがあればattachする指定です。

## tmux内でセッションを離れる

| やりたいこと | キー | 動作 |
| --- | --- | --- |
| セッションから離れる | `Ctrl-b → d` | detach。中の作業は継続 |
| セッション一覧から選ぶ | `Ctrl-b → s` | sessionsを表示 |
| セッション・ウィンドウ・ペインから選ぶ | `Ctrl-b → w` | tree modeを表示 |
| キー一覧 | `Ctrl-b → ?` | 現在の割り当てを表示 |

デタッチはtmuxとの接続を離す操作です。Vimを終了する操作ではありません。

## ウィンドウを操作する

| やりたいこと | キー | 動作 |
| --- | --- | --- |
| 新しいウィンドウ | `Ctrl-b → c` | create window |
| ウィンドウ名を変更 | `Ctrl-b → ,` | rename window |
| 次・前のウィンドウ | `Ctrl-b → n`・`Ctrl-b → p` | next・previous |
| 番号で移動 | `Ctrl-b → 0`〜`9` | 指定番号へ移動 |
| ウィンドウ一覧 | `Ctrl-b → w` | tree modeから選択 |
| 現在のウィンドウを閉じる | 中のシェルで`exit` | 最後のペインが閉じる |

## ペインを分割する

| やりたいこと | キー | 動作 |
| --- | --- | --- |
| 左右に分割 | `Ctrl-b → %` | ペインを横方向へ並べる |
| 上下に分割 | `Ctrl-b → "` | ペインを縦方向へ並べる |
| ペイン間を移動 | `Ctrl-b → 矢印キー` | 指定方向へ移動 |
| 最大化・元に戻す | `Ctrl-b → z` | zoomを切り替える |
| ペインを閉じる | `Ctrl-b → x` | 確認後に対象ペインを終了 |

`%`は左右に並ぶ分割、`"`は上下に並ぶ分割です。分割線の向きではなく、完成したペインの並びで覚えます。

## 過去の出力を見る

| やりたいこと | キー | 動作 |
| --- | --- | --- |
| コピーモードへ入る | `Ctrl-b → [` | 過去の出力を移動できる状態にする |
| 上下へ移動 | `矢印キー`・`PageUp`・`PageDown` | 出力をさかのぼる |
| コピーモードを終了 | `q` | 通常のペインへ戻る |

tmuxは複数の画面を独自に保持するため、ターミナル本体のスクロール履歴と一致しない場合があります。過去の出力はtmuxのコピーモードで確認します。

## SSH先で作業を保持する

```bash
ssh dev-server
tmux new -A -s work
```

作業中に`Ctrl-b → d`でデタッチします。SSHへ再接続したあと、次で同じセッションへ戻ります。

```bash
tmux attach -t work
```

tmuxセッションは接続から離れてもサーバー上で動き続けますが、サーバーの再起動やtmuxセッション自体の終了後には残りません。

## Vimとtmuxを混同しない

| やりたいこと | Vim・Neovim | tmux |
| --- | --- | --- |
| エディタを保存して終了 | `:wq` | 該当なし |
| エディタを保存せず終了 | `:q!` | 該当なし |
| 作業画面から一時的に離れる | 該当なし | `Ctrl-b → d` |
| エディタ画面を分割 | `:sp`・`:vs` | 該当なし |
| ターミナルを分割 | 該当なし | `Ctrl-b → %`・`Ctrl-b → "` |

<Callout type="warning" title="Ctrl-b → dはVimを終了しない">
Vimを開いたまま`Ctrl-b → d`を押すと、tmuxから離れるだけです。Vimを終了する場合はtmuxへ戻り、Vim側で`:q`や`:wq`を実行します。
</Callout>

## マウスと任意の最小設定

執筆時に実機確認したtmux 3.8では、`mouse`の既定値が`on`へ変更されています。手元の値は次で確認できます。

```bash
tmux show-options -gv mouse
```

`off`と表示された版でマウス操作を使う場合や、値を明示したい場合は`~/.tmux.conf`へ次を書きます。

```tmux
# マウスでペイン選択、サイズ変更、スクロールを行う
set -g mouse on
```

コピーモードをVim風のキーに変える設定は、tmux 3.8でも任意です。

```tmux
# コピーモードをVim風のキーにする
setw -g mode-keys vi
```

保存後は、実行中のtmuxから設定を読み直せます。

```bash
tmux source-file ~/.tmux.conf
```

プレフィックスキーを`Ctrl-a`へ変更する設定や、特定のターミナル・AIツール専用設定は、このチートシートでは扱いません。既定の`Ctrl-b`を基準にします。

これでVim、Neovim・LazyVim、tmuxの操作を目的別に引けるようになりました。突然Vimが開いた場合は[Vimコマンドチートシート](/books/vim/vim-cheatsheet)、SSH先での判断は[Git commitとSSH先のVim](/books/vim/vim-in-real-work)へ戻って確認できます。

Vimでは、現在のモードによって同じキーの役割が変わります。文字が入力できないときや、`j`でカーソルが動いたときはモードを確認します。

<Marker>モードは「Vimが次のキー入力を何として解釈するか」を決める状態です。</Marker>

## 最初に覚える4つのモード

| モード | 役割 | 入り方 | 戻り方 |
| --- | --- | --- | --- |
| ノーマル | 移動、削除、コピー | 起動直後 | — |
| 挿入 | 文字入力 | `i`、`a`、`o` | `Esc` |
| ビジュアル | 範囲選択 | `v`、`V` | `Esc` |
| コマンドライン | 保存、終了、検索 | `:`、`/`、`?` | `Enter`または`Esc` |

ノーマルモードが操作の起点です。現在地が分からなくなったら`Esc`を押します。

## 挿入モードへ入る位置を選ぶ

| コマンド | 元の語 | 入力開始位置 |
| --- | --- | --- |
| `i` | insert | カーソルの前 |
| `a` | append | カーソルの後ろ |
| `I` | Insert | 行の最初の文字 |
| `A` | Append | 行末 |
| `o` | open below | 下に新しい行 |
| `O` | Open above | 上に新しい行 |

`|`をカーソル位置とします。

```text
操作前: name = "Ta|ro"
iX後:   name = "TaXro"
aX後:   name = "TarXo"
A;後:   name = "Taro";
```

入力し終えたら`Esc`で戻ります。

<SpeechBubble character="/images/usingcomputer_suit_woman_color.png" name="学習者">
矢印キーで移動できるなら、ずっと挿入モードでもよくないですか？
</SpeechBubble>

短い修正では構いません。ただし削除、コピー、検索結果の移動はノーマルモードを起点に組み合わせるため、入力後に戻る方が操作を見失いません。

## ビジュアルモードで選ぶ

| コマンド | 選択単位 |
| --- | --- |
| `v` | 文字単位 |
| `V` | 行単位 |
| `Ctrl+v` | 矩形 |

選択後に`d`で削除、`y`でコピーします。`d`はdelete、`y`はyank（引き抜く）の頭文字です。

## オペレーター待機モード

`d`や`c`の直後、Vimは適用範囲を待ちます。この状態が**オペレーター待機モード**です。

```text
d  +  w  =  dw
削除   次の単語まで
```

`d`だけで止まったように見えても故障ではありません。やめるなら`Esc`を押します。

## よくあるハマりどころ

- 日本語入力のままノーマルモードへ戻ると英字コマンドを打ちにくい
- `i`と`I`、`v`と`V`は別のコマンド
- 設定によって`-- INSERT --`などの表示が消えていることがある
- コマンドライン入力をやめるときも`Esc`を使える

## ちゃんと使うためのポイント

- ノーマルモードを移動・編集の起点にする
- `i`は前、`a`は後ろ、`o`は下の新しい行から入力する
- `v`は文字単位、`V`は行単位の選択
- `:`は保存や終了、`/`は前方検索を始める
- 迷ったら`Esc`を押す

[カーソル移動](/books/vim/cursor-movement)では、`h`、`j`、`k`、`l`から`gg`、`G`までを使い分けます。

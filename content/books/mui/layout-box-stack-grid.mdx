MUIには、レイアウトのためのコンポーネントが4つあります。役割が少しずつ重なっているので、最初は「どれを使えばいいのか」で迷います。

先に結論を出しておきます。

| コンポーネント | 役割 | 使う場面 |
| --- | --- | --- |
| `Box` | スタイルを当てるための箱 | `div` の代わり。`sx` を使いたいとき |
| `Stack` | 一方向に並べる | 縦並び・横並び。要素間の間隔を揃えたいとき |
| `Container` | 中央に寄せて最大幅を決める | ページ全体の外枠 |
| `Grid` | 12分割のグリッドに配置 | カードを3列に並べるなど、2次元の配置 |

<SpeechBubble character="/images/usingcomputer_suit_woman_color.png" name="学習者">
`Box` と `Stack` ってどっちも箱に見えるんだけど、何が違うの？
</SpeechBubble>

<Marker>`Box` は「1つの箱」、`Stack` は「複数を並べる入れ物」</Marker>です。並べたいものが複数あるなら `Stack`、単体にスタイルを当てたいだけなら `Box` と考えてください。

## Box — sxを使うための箱

`Box` は、レンダリングすると `<div>` になるだけのコンポーネントです。特別な見た目は持ちません。存在理由は `sx` を使えるようにすることです。

```tsx
<Box sx={{ p: 2, border: '1px solid', borderColor: 'grey.300', borderRadius: 1 }}>
  囲まれた中身
</Box>
```

`component` propで、実際に出力されるHTMLタグを変えられます。

```tsx
<Box component="section" sx={{ py: 4 }}>
  <Box component="h2" sx={{ m: 0 }}>見出し</Box>
</Box>
```

見た目は `sx` で決めつつ、HTMLとしての意味は正しく保てます。

<Callout type="info" title="Boxを使わずに済む場面も多い">
MUIのコンポーネントはほぼすべてが `sx` を受け取るので、`<Box sx={{ mt: 2 }}><Button /></Box>` と包むより `<Button sx={{ mt: 2 }} />` と直接書けることが多いです。`Box` が要るのは、MUIのコンポーネントではない素の要素にスタイルを当てたいときです。
</Callout>

## Stack — 並べて間隔を揃える

`Stack` は、子要素を縦か横に並べ、あいだに均等な間隔を空けます。中身はFlexboxです。

```tsx
<Stack spacing={2}>
  <TextField label="名前" />
  <TextField label="メールアドレス" />
  <Button variant="contained">送信</Button>
</Stack>
```

`spacing={2}` は `sx` と同じくspacingの倍数なので、16pxの間隔になります。

横並びにするには `direction` を変えます。

```tsx
<Stack direction="row" spacing={1}>
  <Button>キャンセル</Button>
  <Button variant="contained">保存</Button>
</Stack>
```

レスポンシブにも書けます。狭い画面では縦、広い画面では横、という指定です。

```tsx
<Stack direction={{ xs: 'column', md: 'row' }} spacing={2}>
```

### 揃え方はsxで指定する

「タイトルを左、ボタンを右」「高さの違う要素を縦中央で揃える」といった揃え方は、`sx` にFlexboxのプロパティを書きます。

```tsx
<Stack direction="row" sx={{ alignItems: 'center', justifyContent: 'space-between' }}>
  <Typography variant="h6">商品一覧</Typography>
  <Button variant="contained">商品を追加</Button>
</Stack>
```

<Callout type="warning" title="alignItemsをpropとして書くとv9では型エラー">
古い記事には `<Stack direction="row" alignItems="center">` のように、CSSプロパティをそのままpropとして渡す書き方が出てきます。v9の `Stack` の型には `alignItems` も `justifyContent` も定義されておらず、型エラーになります。`sx` の中に移してください。
</Callout>

### dividerで区切り線を入れる

要素のあいだに区切り線を挟みたいときは、自分で `<Divider />` を並べる必要はありません。

```tsx
<Stack divider={<Divider flexItem />} spacing={2}>
  <Box>1つ目</Box>
  <Box>2つ目</Box>
  <Box>3つ目</Box>
</Stack>
```

子要素の**あいだにだけ**挿入されるので、末尾に余計な線が残りません。

<Figure src="/images/deta_man_color.png" alt="要素を並べて整えるイメージ" maxWidth="230px" />

### spacingの実体はmargin。折り返すならuseFlexGap

`Stack` の `spacing` は、既定ではCSSの `gap` ではなく**子要素の `margin`** で実装されています。`@mui/system` の `createStack.js` を読むと、次の2つのスタイルを出力しています。

| セレクタ | 出力されるスタイル |
| --- | --- |
| すべての直下の子 | `margin: 0` |
| 2つ目以降の子 | `margin-top`（横並びなら `margin-left`）に `spacing` の値 |

この実装から、2つの挙動が生まれます。

- **子要素に書いた `margin` が効かない。** `Stack` が直下の子の `margin` を0で上書きするためです。`<Button sx={{ mt: 4 }}>` と書いても間隔は変わりません
- **折り返すと2行目の間隔が崩れる。** `margin-left` は横方向にしか付かないので、`flexWrap: 'wrap'` で折り返した行のあいだには間隔ができず、行頭の要素にも余白が付きます

どちらも `useFlexGap` を付けると解消します。`spacing` が `gap` で出力されるようになり、子の `margin` を上書きしなくなります。

```tsx
<Stack direction="row" spacing={1} useFlexGap sx={{ flexWrap: 'wrap' }}>
  <Chip label="React" />
  <Chip label="TypeScript" />
  <Chip label="MUI" />
</Stack>
```

タグの一覧のように、数が決まっておらず折り返す可能性がある横並びには `useFlexGap` を付けておきます。

## Container — 中央寄せと最大幅

`Container` は、中身を画面中央に寄せ、広がりすぎないように最大幅を設けます。ページ全体の外枠として使います。

```tsx
<Container maxWidth="md">
  <h1>ページタイトル</h1>
</Container>
```

`maxWidth` にはブレークポイントのキーを渡します。**デフォルトは `lg`** です。

| 指定 | 最大幅の目安 |
| --- | --- |
| `maxWidth="sm"` | 600px |
| `maxWidth="md"` | 900px |
| `maxWidth="lg"` | 1200px（デフォルト） |
| `maxWidth="xl"` | 1536px |
| `maxWidth={false}` | 制限なし |

左右の余白も自動で入るので、スマートフォンで文字が画面端に貼り付くのを防げます。

## Grid — v9で書き方が変わった

ここが本章の要注意ポイントです。

<SpeechBubble character="/images/question_woman_04_color.png" name="学習者">
`<Grid item xs={6}>` って書いたら型エラーが出た。記事のとおりに書いたのに…。
</SpeechBubble>

v9で `Grid` の書き方が刷新されました。<Marker>`item` と `xs` は廃止され、`size` propに一本化されています</Marker>。

```tsx
// v8以前。v9では動かない
<Grid container spacing={2}>
  <Grid item xs={12} md={6}>左</Grid>
  <Grid item xs={12} md={6}>右</Grid>
</Grid>
```

v9では次のように書きます。

```tsx
<Grid container spacing={2}>
  <Grid size={{ xs: 12, md: 6 }}>左</Grid>
  <Grid size={{ xs: 12, md: 6 }}>右</Grid>
</Grid>
```

変更点は2つです。

- `item` を書かない。`container` が付いていない `Grid` は自動的にアイテム扱いになる
- ブレークポイントごとの幅は `size` にオブジェクトで渡す。単一の値なら `size={6}` でよい

実際に `Grid` の型が受け取るpropsは `container` / `size` / `spacing` / `columns` / `offset` / `direction` / `wrap` などで、`item` も `xs` も定義されていません。旧v5系の `GridLegacy` もv9で完全に削除されました。

### sizeに渡せる値

| 値 | 意味 |
| --- | --- |
| 数値（`size={6}`） | 12分割のうち何個分か。6なら半分 |
| `'auto'` | 中身の幅に合わせる |
| `'grow'` | 余った幅を埋める |
| `false` | その画面幅では指定しない |

分割数はデフォルトで12ですが、`columns` で変更できます。

```tsx
<Grid container columns={10} spacing={2}>
  <Grid size={3}>3/10の幅</Grid>
</Grid>
```

### offsetで左に空きを作る

`offset` は、アイテムの左側に指定した列数ぶんの空きを作ります。`size` と同じく、ブレークポイントごとの指定もできます。

```tsx
<Grid container spacing={2}>
  {/* 12列のうち、左4列を空けて中央の4列に置く */}
  <Grid size={4} offset={4}>中央のカラム</Grid>
</Grid>

<Grid container spacing={2}>
  <Grid size={3}>左端</Grid>
  {/* 残りの空きをすべて左側に取り、右端に寄せる */}
  <Grid size={3} offset="auto">右端</Grid>
</Grid>
```

### 縦積みにGridは使わない

v9では `direction="column"` が使えなくなりました。型も `'row' | 'row-reverse'` だけを受け付けます。

<Callout type="warning" title="縦に積むならStack">
`Grid` の縦積みは以前から不具合の原因になりやすく、v9で正式に非対応になりました。縦に並べたいときは `Stack` を使ってください。`Grid` は「横方向の分割」に用途が絞られたと考えると分かりやすいです。
</Callout>

## どれを選ぶかの判断

<SpeechBubble character="/images/oksign_man_color.png" name="先生" side="right">
実務では `Stack` で大半が片付きます。`Grid` の出番は「カードを画面幅に応じて3列・2列・1列に変えたい」のような、明確に列を数えたいときだけです。
</SpeechBubble>

判断の順番はこうなります。

1. 並べたいものが1つだけ、スタイルを当てたい → **`Box`**
2. 一方向に並べたい → **`Stack`**
3. 画面幅に応じて列数を変えたい → **`Grid`**
4. ページ全体の外枠 → **`Container`**

## 4つを組み合わせて1ページを作る

実際の画面では、4つを入れ子にして使います。商品一覧ページを例に、それぞれの担当を確認します。

```tsx
import { Box, Button, Card, CardContent, Container, Grid, Stack, Typography } from '@mui/material';

const products = [
  { id: 1, name: 'ノート', price: 480 },
  { id: 2, name: 'ペン', price: 120 },
  { id: 3, name: '付箋', price: 300 },
];

export function ProductListPage() {
  return (
    <Container maxWidth="lg" sx={{ py: 4 }}>
      <Stack spacing={3}>
        <Stack direction="row" sx={{ alignItems: 'center', justifyContent: 'space-between' }}>
          <Typography variant="h4" component="h1">
            商品一覧
          </Typography>
          <Button variant="contained">商品を追加</Button>
        </Stack>

        <Grid container spacing={2}>
          {products.map((product) => (
            <Grid key={product.id} size={{ xs: 12, sm: 6, md: 4 }}>
              <Card>
                <CardContent>
                  <Typography variant="h6" component="h2">
                    {product.name}
                  </Typography>
                  <Box sx={{ mt: 1, color: 'text.secondary' }}>{product.price}円</Box>
                </CardContent>
              </Card>
            </Grid>
          ))}
        </Grid>
      </Stack>
    </Container>
  );
}
```

| コンポーネント | このページでの担当 |
| --- | --- |
| `Container` | ページ全体を中央に寄せ、幅を最大1200pxに抑える |
| 外側の `Stack` | 見出しの行とカード一覧を縦に並べ、あいだを24px空ける |
| 内側の `Stack` | 見出しとボタンを横に並べ、左右の端に分ける |
| `Grid` | カードを画面幅に応じて1列（`xs`）・2列（`sm`）・3列（`md`）に切り替える |
| `Box` | MUIのコンポーネントではない価格の表示に、`sx` で余白と色を当てる |

`xs`・`sm`・`md` が指す画面幅は[レスポンシブとブレークポイントの章](/books/mui/responsive-and-breakpoints)で扱っています。

## よくあるハマりどころ

### `<Grid item>` が型エラーになる

v9の変更です。`item` を消して `size` に書き換えます。

### 古い記事にあるGridの余白回避策を持ち込んでしまう

`<Grid container sx={{ width: 'calc(100% + 16px)' }}>` のような調整を書いている記事がありますが、**v9では不要です**。v9の `Grid` は `spacing` をCSSの `gap` で実装しており（`@mui/system` の `gridGenerator.js` で確認できます）、コンテナからはみ出す挙動は起きません。回避策のほうがレイアウトを壊します。

### Stackのspacingが効かない

原因は3つあります。

- **子要素が1つしかない。** `spacing` は「あいだ」の指定なので、間隔は生まれません。要素の外側に余白が欲しいときは `sx={{ p: 2 }}` を使います
- **子を1つの `div` にまとめている。** `Stack` が間隔を付けるのは、DOM上の直下の子だけです。`<Stack><div>…複数の要素…</div></Stack>` では、`div` の中の要素どうしには間隔が付きません
- **折り返している。** 既定の実装は `margin` なので、折り返した行のあいだには間隔ができません。`useFlexGap` を付けます

### Stackの子に書いたmarginが効かない

`Stack` が直下の子の `margin` を0にしているためです。その要素だけ間隔を変えたいなら、`useFlexGap` を付けたうえで子に `margin` を書くか、`Stack` を分けます。

## ちゃんと使うためのポイント

- `Box` は `sx` を使うための箱。`div` の置き換え
- <Marker>並べるなら `Stack`。縦横の切り替えも `direction` だけで済む</Marker>
- `Container` はページの外枠。`maxWidth` のデフォルトは `lg`
- <Marker>v9の `Grid` は `<Grid size={{ xs: 12, md: 6 }}>`。`item` と `xs` は廃止</Marker>
- `Grid` で縦積みはできない。縦は `Stack`
- `Stack` の `spacing` は既定で `margin`。折り返す横並びや、子に `margin` を書きたい場面では `useFlexGap`
- 揃え方（`alignItems` / `justifyContent`）は `sx` に書く

文字の見た目とHTMLタグを分けて指定する仕組みは、[Typographyコンポーネントの章](/books/mui/typography)で扱っています。

## 基本の使い方

```html
<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-gray-100">
  <p>テキスト</p>
  <button class="bg-blue-600 dark:bg-blue-500 text-white">
    ボタン
  </button>
</div>
```

ダークモードは `dark:bg-black dark:text-white` のように極端な反転だけで済ませると、目に強すぎたり、補助テキストが読みにくくなったりします。`gray-900` / `slate-900` などの濃いグレーを背景にし、本文は `gray-100`、補助テキストは `gray-400` 程度に分けると自然です。

## OSの設定に連動（デフォルト）

デフォルトでは `prefers-color-scheme: dark` メディアクエリに連動します。ユーザーのOS設定が「ダーク」のときに `dark:` クラスが有効になります。

<Callout type="info">
macOSでは「システム設定 > 外観モード > ダーク」、Windowsでは「設定 > 個人用設定 > 色 > ダーク」でOS側のダークモードを切り替えられます。開発時のテストに活用しましょう。
</Callout>

```html
<!-- OS設定がダークのとき自動でダークモード -->
<body class="bg-white dark:bg-gray-950">
  ...
</body>
```

## 手動切り替え（クラスベース）

ボタンでテーマを切り替えたい場合は、`html` 要素に `dark` クラスを付け外しします。

**v4 の設定：**

```css
/* globals.css */
@import "tailwindcss";

@variant dark (&:where(.dark, .dark *));
```

**v3 の設定：**

```js
// tailwind.config.js
module.exports = {
  darkMode: 'class',
  // ...
}
```

**React でのトグル実装：**

```tsx
function ThemeToggle() {
  const toggleDark = () => {
    document.documentElement.classList.toggle('dark')
  }
  return <button onClick={toggleDark}>テーマ切り替え</button>
}
```

## ちゃんと使うためのポイント

- <Marker>`dark:` クラスはライト用クラスと並べて書く（`bg-white dark:bg-gray-900`）</Marker>
- OS連動で十分な場合はデフォルト設定のまま使う
- ボタンで切り替えるなら `darkMode: 'class'`（v3）または `@variant dark`（v4）を設定
- 色の選択はライト・ダーク両方で確認する

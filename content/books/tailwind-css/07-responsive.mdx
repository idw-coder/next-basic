## ブレークポイントプレフィックス

| プレフィックス | 幅 | 対象 |
|---|---|---|
| （なし） | 全幅（モバイル） | デフォルト |
| `sm:` | 640px〜 | 大きめスマートフォン |
| `md:` | 768px〜 | タブレット |
| `lg:` | 1024px〜 | ノートPC |
| `xl:` | 1280px〜 | デスクトップ |
| `2xl:` | 1536px〜 | 大画面 |

---

## モバイルファースト

Tailwindはモバイルファーストです。プレフィックスなしのクラスがデフォルト（最小幅）で、プレフィックスを付けると「その幅以上のとき」適用されます。

<Callout type="warning">
よくある間違い：`sm:` を「スマートフォン向け」と思ってしまうこと。`sm:` は「640px以上」に適用されるので、むしろタブレット以上向けです。スマートフォン向けはプレフィックスなしで書きます。
</Callout>

```html
<!-- スマホ: 1列、タブレット: 2列、PC: 3列 -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
  ...
</div>
```

<TailwindPreview title="画面幅で列数が変わるカード一覧">
  <div className="grid grid-cols-1 gap-3 md:grid-cols-2 lg:grid-cols-3">
    <div className="rounded-md border border-slate-200 bg-slate-50 p-4">
      <p className="text-sm font-semibold text-slate-900">スマホ</p>
      <p className="mt-1 text-xs text-slate-500">1列で読みやすく表示</p>
    </div>
    <div className="rounded-md border border-slate-200 bg-white p-4">
      <p className="text-sm font-semibold text-slate-900">タブレット</p>
      <p className="mt-1 text-xs text-slate-500">md以上で2列に変更</p>
    </div>
    <div className="rounded-md border border-slate-200 bg-white p-4">
      <p className="text-sm font-semibold text-slate-900">PC</p>
      <p className="mt-1 text-xs text-slate-500">lg以上で3列に拡張</p>
    </div>
  </div>
</TailwindPreview>

この例では `grid-cols-1` がすべての画面幅の基本になり、`md:grid-cols-2` と `lg:grid-cols-3` が上書きしていきます。レスポンシブは「スマホ用を別に作る」のではなく、**小さい画面の自然な見た目をベースにして、大きい画面だけ拡張する**と考えると安定します。

## よく使うパターン

### 横並びを画面幅で切り替え

```html
<!-- スマホは縦、PC以上は横 -->
<div class="flex flex-col md:flex-row gap-4">
  <aside class="w-full md:w-64">サイドバー</aside>
  <main class="flex-1">メイン</main>
</div>
```

### テキストサイズ

```html
<h1 class="text-2xl md:text-4xl lg:text-5xl font-bold">
  タイトル
</h1>
```

### 表示・非表示

```html
<!-- スマホでは非表示、md以上で表示 -->
<nav class="hidden md:flex gap-4">...</nav>

<!-- スマホでは表示、md以上で非表示（ハンバーガーメニューアイコンなど） -->
<button class="md:hidden">メニュー</button>
```

### padding

```html
<section class="py-8 md:py-16 lg:py-24">
  ...
</section>
```

## max- プレフィックス（上限指定）

v3.2以降、`max-md:` のように上限を指定できます。

```html
<!-- md未満のときのみ適用 -->
<div class="max-md:hidden">タブレット以上で表示</div>
```

## ちゃんと使うためのポイント

- <Marker>プレフィックスなし = スマートフォン向けがデフォルト</Marker>
- `sm:` / `md:` / `lg:` のどれか2〜3つを一貫して使えばほとんどのケースに対応できる
- `hidden md:block` でスマートフォン非表示は頻出パターン

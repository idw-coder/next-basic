## 扱うトピック

### .d.tsファイルとは

型情報だけを記述したファイル。実装コードは含まない。TypeScriptコンパイラはこのファイルを見て型チェックを行う。

### @types パッケージ

```bash
npm install --save-dev @types/react @types/node
```

DefinitelyTypedリポジトリでコミュニティが管理する型定義パッケージの仕組みを解説予定です。

### 型定義が同梱されているライブラリ

`axios`、`zod`、`date-fns` など、ライブラリ本体に `.d.ts` が含まれているケース。`@types` が不要な場合の見分け方を解説予定です。

### 型定義がないライブラリへの対処

`declare module` で最低限の型定義を書く方法を解説予定です。

### グローバル型定義

`global.d.ts` でプロジェクト全体の型を拡張する方法を解説予定です。

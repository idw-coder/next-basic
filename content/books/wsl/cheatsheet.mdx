## ディストリビューションの管理（PowerShell）

| コマンド | 動作 | 章 |
| -------- | ---- | -- |
| `wsl -l -v` | 一覧・状態・WSLのバージョン | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl` / `wsl ~` | 既定のディストリビューションを起動する（`~` はホームから） | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl -d Ubuntu` | 指定したディストリビューションを起動する | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl -u root` | rootユーザーで起動する | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl --set-default Ubuntu` | 既定のディストリビューションを変える | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl --terminate Ubuntu` | 指定したディストリビューションを停止する | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl --shutdown` | すべてのディストリビューションと仮想マシンを停止する | [wslコマンド](/books/wsl/wsl-command-and-distros) |
| `wsl --set-version Ubuntu 2` | WSL1からWSL2に変換する | [wslコマンド](/books/wsl/wsl-command-and-distros) |

## 設定ファイル

| やりたいこと | ファイル | 書く内容 | 章 |
| ------------ | -------- | -------- | -- |
| メモリの上限 | `.wslconfig` | `[wsl2]` `memory=8GB` | [設定ファイル](/books/wsl/wslconfig-and-wsl-conf) |
| CPUの数 | `.wslconfig` | `[wsl2]` `processors=4` | [設定ファイル](/books/wsl/wslconfig-and-wsl-conf) |
| ミラーモード | `.wslconfig` | `[wsl2]` `networkingMode=mirrored` | [ネットワーク](/books/wsl/networking) |
| systemdを有効にする | `/etc/wsl.conf` | `[boot]` `systemd=true` | [設定ファイル](/books/wsl/wslconfig-and-wsl-conf) |
| WindowsのPATHを混ぜない | `/etc/wsl.conf` | `[interop]` `appendWindowsPath=false` | [Windowsとの連携](/books/wsl/windows-interop) |
| 既定のユーザー | `/etc/wsl.conf` | `[user]` `default=ユーザー名` | [設定ファイル](/books/wsl/wslconfig-and-wsl-conf) |

`.wslconfig` は `C:\Users\ユーザー名\.wslconfig`、`wsl.conf` は各ディストリビューションの `/etc/wsl.conf` に置きます。どちらも、編集したら `wsl --shutdown` を実行してから起動し直します。

## トラブルのときに最初に確認すること

| 症状 | 最初に確認すること | 章 |
| ---- | ------------------ | -- |
| 動作がおかしい | `wsl --shutdown` → `wsl --update` | [トラブル対処](/books/wsl/troubleshooting) |
| 遅い | `pwd` が `/mnt/c` で始まっていないか | [トラブル対処](/books/wsl/troubleshooting) |
| Windowsのメモリが足りない | タスクマネージャーの `VmmemWSL`、`.wslconfig` の `memory` | [トラブル対処](/books/wsl/troubleshooting) |
| Cドライブが減り続ける | 仮想ディスクの縮小 | [トラブル対処](/books/wsl/troubleshooting) |
| `localhost` に繋がらない | `ss -tlnp` で待ち受けアドレスを確認 | [ネットワーク](/books/wsl/networking) |
| `npm` の動きがおかしい | `which npm` が `/mnt/c` を指していないか | [Node.jsを入れる](/books/wsl/dev-runtimes) |
| `bad interpreter` と `^M` | 改行コードがCRLFになっていないか | [Windowsとの連携](/books/wsl/windows-interop) |
| `apt update` で `not valid yet` | `date` で時刻がずれていないか | [トラブル対処](/books/wsl/troubleshooting) |
| `docker` が見つからない | Docker Desktopの「WSL Integration」 | [Docker](/books/wsl/docker-on-wsl) |
